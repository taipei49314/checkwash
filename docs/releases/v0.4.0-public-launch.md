# v0.4.0 candidate and release record

**Status: preparation and qualification in progress; not yet published.**
The user authorized this version under estate T-436. The integration is
[PR #160](https://github.com/taipei49314/checkwash/pull/160).

This round covers the 17 open issues inventoried from the repository:
84–93, 95, 130, 132, 140, 156, 158 and 159. An issue remains open until
its reported behavior is resolved and verified; this list is scope, not a
claim that every issue has been closed.

The candidate adds bounded proofs for pytest execution/report hooks,
collection settings, fixture subject replacement and import-path providers;
expectation provenance, inherited test methods, checked doctest examples and
literal branch outcomes; and additional transparent table refactors. The
JavaScript scanner distinguishes real test declarations from comments,
strings and regular expressions, and duplicate test names retain their
individual multiplicity during alignment.

## Try it on a change you understand

After publication, use Python 3.11+ and Git:

```sh
pipx install checkwash==0.4.0
checkwash --version
checkwash demo
checkwash check HEAD~1..HEAD --format json
```

`23fce200561ae4a95e46539ed9e668088591d1c1`. It does not include the new
v0.4.0 detector and precision changes. Record the CLI and Action versions
separately. Alpha status, remaining bounded-model gaps and the distinction
between an engine replay and runtime label qualification remain explicit.
