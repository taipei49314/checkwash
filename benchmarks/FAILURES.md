# Known failures

Generated by `benchmarks/make_failures.py` from `THREATMODEL.md`, the
adjudication files and the recorded decoy arms. Nothing here is
hand-typed; if something is missing from this page it is missing from
those files.

This is the page to read before installing. Every other document in
this repository argues that the tool works; this one collects every way
it is known not to.

## The short version

- **103 bypasses** are documented, of which **24 are not closed**.
- **21 of 1800** human-written commits are blocked by mistake (1.17%), each one named below.
- **2 false positives were shipped and corrected**, both found by
  adversarial review rather than by this project's own review.
- A production file greenwash cannot read suppresses escalation for the
  whole diff. That is the largest hole and it is by design.
